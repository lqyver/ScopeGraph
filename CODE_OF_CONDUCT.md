# Code of Conduct

ScopeGraph aims to be a welcoming, respectful learning and collaboration space.
We expect participants to be constructive, inclusive, and careful with the
security and privacy of others.

Unacceptable behaviour includes harassment, discrimination, publishing private
or third-party scan data, disclosing credentials or personal data, encouraging
unauthorized testing, or using project spaces to target systems without
permission.

For conduct concerns, use the same private contact route described in
[SECURITY.md](./SECURITY.md). Maintainers should handle reports discreetly,
fairly, and without retaliation.
