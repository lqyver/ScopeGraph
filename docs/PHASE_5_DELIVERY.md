# 阶段 5 交付记录

## 阶段名称

企业名称发现、归属评分、人工审核与覆盖评估。

## 完成内容

- 企业名称规范化、别名和常见公司后缀处理；
- 本地、录制公开证据、搜索、证书透明度和 RDAP 五类受限 Source Adapter；候选源平台自身域名进入拒绝表；
- 已发现候选可由证书 SAN 和公开 RDAP 注册人精确匹配佐证，均有来源、请求完成度和失败诊断；
- 企业发现支持 `202 RUNNING` 异步执行和逐来源持久化进度；Web 自动轮询运行记录，逐步显示搜索、证书和 RDAP 的结果，而非等待整条流程结束；
- 版本化归属规则 `configs/ownership_rules/v2.json`，每个分值均可追溯到证据；
- 企业发现运行、候选根域、证据哈希和人工审核记录的数据库模型与 `0007` 迁移；
- 候选确认、排除、手工补充、批量审核和审计日志；人工决定不会被后续自动评分覆盖；
- 任务完成度与覆盖度分离，缺少候选时明确返回 `NO_CANDIDATE_ROOTS`；
- 企业发现、审核队列、证据和覆盖评估 Web 页面及 CLI。

## 自动验收

Phase 5 E2E 验证了企业名称空结果、录制证据发现、证据幂等、人工确认加入 Scope、人工覆盖
保持和覆盖度计算。实测：`example.com` 候选、4 条持久证据、人工状态 `CONFIRMED`，任务状态
仍独立为 `NOT_STARTED`。

异步验收还验证了运行会先返回 `RUNNING` 和来源计划，随后通过运行详情接口达到 `SUCCESS` 和
100% 进度；来源完成状态由 worker 持久化，API 重启或页面刷新不会丢失已完成的诊断。

## 安全边界

自动评分永远不直接授权主动扫描；搜索结果中的第三方平台域名不会成为候选；公开查询有固定
超时、结果上限、可信响应主机限制和逐来源错误记录；只有明确人工决定才创建 Scope 规则。
